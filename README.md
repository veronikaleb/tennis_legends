# 🎾 Tennis Legends

**Tennis Legends** is an interactive platform dedicated to exploring the rich heritage of professional tennis. The project traces the evolution of the sport from the 1970s to the modern era of Big Data, focusing on the iconic personalities and key milestones that shaped the game.

## 🌟 Key Sections

*   **Timeline of Excellence:** A historical journey through the decades (1970s–2020s), showcasing changes in technology and playing styles.
*   **Ukrainian Tennis Heritage:** A dedicated section celebrating the achievements of Ukrainian players, including Elina Svitolina, the Bondarenko sisters, and the Kichenok sisters.
*   **Tournament Hierarchy:** A detailed breakdown of the professional tour structure—from ITF entry-level events to elite Grand Slams and the ATP/WTA Finals.
*   **Hall of Fame:** In-depth career analysis of legends like Roger Federer, Rafael Nadal, and Novak Djokovic.

## 🛠 Technical Stack

*   **Frontend:** HTML.
*   **Styling:** Tailwind CSS (featuring sports-grade typography and mobile-first responsive design).
*   **Hosting:** GitHub Pages.
